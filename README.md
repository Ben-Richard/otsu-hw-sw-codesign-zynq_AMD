# otsu-hw-sw-codesign-zynq_AMD
FPGA-based HW/SW co-design implementation of Otsu image thresholding on Zynq using Verilog, AXI-Stream, AXI-Lite, DMA, DDR and Vitis software. The FPGA accelerates histogram generation and pixel thresholding while the ARM processor calculates the optimum Otsu threshold.
